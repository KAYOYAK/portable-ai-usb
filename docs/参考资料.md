## 0. 我做的每一步 ← 出处对照

| 我做的事 | 依据 / 出处 |
|---|---|
| 用 `llama-<tag>-bin-win-cpu-x64.zip` 而不是自己编译 | llama.cpp GitHub Releases 的资产命名规律（见 §1.2） |
| 为什么不用 `releases/latest` | `latest` = `v0.7.0`，只挂了 `nightly-tag.txt`，**没有二进制**；二进制只挂在 `b####` tag 上（见 §1.2，已实测） |
| 为什么把 `vcruntime140.dll` / `msvcp140.dll` 塞进引擎目录 | 微软官方「动态链接库搜索顺序」——exe 同目录优先级最高，这叫 **app-local 部署**（见 §5.1） |
| 为什么 U 盘必须从 FAT32 改成 exFAT | FAT32 单文件上限 4 GB，模型 6.4 GB；exFAT 无大小限制且三大系统免驱（见 §5.3） |

| 为什么 exFAT 上的文件不会被 SmartScreen 拦 | 「从网上下载」这个标记是 NTFS 的 **ADS（Zone.Identifier）**，exFAT 文件系统本身不支持 ADS（见 §5.4） |
| 三级降级 cuda13 → vulkan → cpu | `llama-server --list-devices` 能列出真正可用的后端；llama.cpp 的多后端构建（见 §1.3、§1.4） |
| `--cache-type-k q8_0` 这种 KV 量化省显存 | `tools/server/README.md`（114 KB，所有参数的权威出处，见 §1.3） |
| 上下文按显存自动选档 | MiMo 的 `config.json` 里 `num_hidden_layers: 32` 但只有 8 层是 `full_attention`，其余是 `linear_attention` → KV 缓存比同尺寸常规模型小一个数量级（见 §2.3） |

- README 原文：`llama serve -hf ggml-org/MiMo-V2.6-Distill-Qwen-9B-GGUF`

### 2.3 全部量化档位（bartowski 出品，实测字节）
- https://huggingface.co/bartowski/MiMo-V2.6-Distill-Qwen-9B-GGUF
  ```
  Q2_K 3.39G   IQ3_XXS 3.85G   Q3_K_S 3.97G   Q3_K_M 4.17G   IQ3_M 4.51G
  IQ4_XS 4.87G  Q4_K_S 5.11G   Q4_K_M 5.44G   Q4_1 5.54G     Q5_K_S 6.05G
  Q5_K_M 6.40G  Q6_K 7.26G     Q8_0 8.89G     bf16 16.69G      ← 我用的是 Q5_K_M
  ```
- 架构（`config.json`）：`Qwen3_5ForConditionalGeneration` / `model_type: qwen3_5`；
  32 层，`layer_types` 里**每 4 层才 1 层 `full_attention`，其余是 `linear_attention`**；
  `num_key_value_heads: 4`、`head_dim: 256`、`max_position_embeddings: 262144`
- KV 缓存算法：8 层全注意力 × 4 KV 头 × 256 head_dim × 2(K+V)
  = **16384 元素/token ≈ 32 KB/token（f16）→ 8K 上下文只要约 256 MB**
  （同尺寸常规模型要 2 GB 以上，这就是它特别适合小显存机的原因）

### 2.4 国内网络下载（本机实测唯一可靠通道）
- HF 官方站 `huggingface.co` 本机**不通**；镜像 **`hf-mirror.com` 可用**
- 取文件：`https://hf-mirror.com/<repo>/resolve/main/<文件名>`
- 取小文件：`https://hf-mirror.com/<repo>/raw/main/<从文件>`

## 5. Windows 便携化的关键机制（这套东西为什么能跑）

### 5.1 DLL 搜索顺序 —— 「不装 VC++ 也能跑」的依据
- https://learn.microsoft.com/zh-cn/windows/win32/dlls/dynamic-link-library-search-order
- exe 所在目录的优先级**高于** `C:\Windows\System32`
- 所以把 `vcruntime140.dll` / `vcruntime140_1.dll` / `msvcp140.dll` 等放在 `llama-server.exe` 旁边，
  目标电脑**装没装 VC++ 运行库都无所谓**——这叫 **app-local 部署**
- 实测证据：从 U 盘启动后查进程模块，`VCRUNTIME140.dll`、`MSVCP140.dll` 的来源路径是 U 盘，不是 System32

### 5.2 取「自己所在目录」（盘符无关）
- cmd 批处理：`%~dp0`（不含引号时结尾带 `\`）
- PowerShell：`$PSScriptRoot`（脚本文件才有；交互式命令行里是空的）
- 备选：`$MyInvocation.MyCommand.Definition`
- 用法：所有路径都用 `Join-Path $Root "..."` 拼，**绝不写死 `E:\`**

### 5.3 文件系统选择 —— 为什么必须 exFAT
- FAT32：**单文件最大 4 GB - 1 字节**（官方规格），6.4 GB 的模型根本放不进去
- NTFS：Windows 上最全，但 macOS 默认**只读**（写要装第三方驱动）
- exFAT：无单文件大小限制、Windows/macOS/Linux 都免驱、针对闪存介质设计
- 参考：https://learn.microsoft.com/zh-cn/windows/win32/fileio/maximum-file-size

### 5.4 「从网上下载」标记 = ADS（这个决定了会不会被 SmartScreen 拦）
- 该标记是 NTFS 的**备用数据流** `Zone.Identifier`，不是文件内容
- **exFAT / FAT32 不支持 ADS** → 文件天然不可能带这个标记
- 所以在 exFAT 的 U 盘上，不存在「拷进去的 exe 被 SmartScreen 拦住」这件事
- 参考（PowerShell 侧）：`Unblock-File` / `Get-Item -Stream *`

### 5.5 免管理员运行
- 便携包全程不需要提权：不写 Program Files、不写 HKLM、不注册服务、不开防火墙规则
- 只绑 `127.0.0.1` → **不会弹 Windows 防火墙授权框**，也不会被局域网扫到

## 6. 性能与硬件参考

- **低端 PC 本地 LLM 实测基准表**（2026-09 更新）：
  https://www.promptquorum.com/zh/local-llms/fastest-local-llms-low-end-pcs
  ```
  4 GB 纯CPU (N100)          + Qwen3 1.7B Q4_K_M  →  25–35 tok/s
  8 GB 纯CPU (i5-1235U)      + Phi-4-mini 3.8B    →  15–22 tok/s
  8 GB + Radeon 核显         + Qwen3 4B           →  18–25 tok/s
  16 GB 纯CPU (7700X)        + Qwen3 8B Q4_K_M    →   8–13 tok/s
  16 GB + Iris Xe            + Llama 3.2 3B       →  20–30 tok/s
  ```
  体感：<10 tok/s 卡顿 ｜ 15–25 可接受 ｜ 30+ 流畅
- **显存/内存规划铁律**：模型 + KV 不超物理内存的 20–30%
- **U 盘速度分级**（冷加载 2.5 GB 模型实测）：
  USB 3.0 普通闪存 17–28 s ｜ USB 3.2 Gen2 6–9 s ｜ 移动固态 2–3 s
  ⚠️ 真正的瓶颈是闪存盘的 **4K 随机读**（1–5 MB/s），不是顺序带宽

## 7. 网络备忘（本机环境特有的坑，换机器请忽略）

- `github.com` / `raw.githubusercontent.com` 在本机被解析到 `127.0.0.1` → 直接抓取会失败
- 可用替代通路：
  - `https://ghproxy.net/https://github.com/...`（网页可用，大文件慢）
  - `https://gh-proxy.com/...`
  - **`https://api.github.com/...` 可直连**（推荐，查发布信息最快）
  - **`https://hf-mirror.com/...` 取 HuggingFace**
- 本机 `curl` 需要加 `--ssl-no-revoke`，否则报 `CRYPT_E_NO_REVOCATION_CHECK`
